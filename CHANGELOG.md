# Changelog

## 0.1.0

- Native SwiftUI macOS asset browser.
- Managed local design library.
- Folder import with normalized names, manifests, thumbnails, SQLite metadata, and computed tags.
- Browsing filters, search, smart collections, shuffle, similar assets, duplicate scan, and visual analysis.
- Inspector preview with variants, background switching, blend modes, pan, zoom, and rotation.
- Shared cart, collections, folder export, and zip export.
- CLI and MCP wrapper.
- Local app packaging scripts with configurable bundle ID and signing identity.
- Repo-owned sample pack, smoke test, unit tests, issue templates, and public verification script.
